# Sentinel Terminal Description

Sentinel Terminal is an AI-first developer operating system. It aims to completely replace traditional terminals by providing a robust native shell environment augmented by an intelligent, local-first agent system.

Unlike wrapper CLIs or simple LLM chatboxes, Sentinel integrates natively with the OS and uses a robust Capability and Workflow Engine. A user can seamlessly alternate between typing traditional shell commands (e.g., `git commit -m "update"`) and natural language requests (e.g., "Disconnect from Wi-Fi"), and the system instantly routes it.

It acts as a trusted OS Assistant running locally on macOS, Windows, and Linux.
